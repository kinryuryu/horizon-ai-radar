## [vLLM v0.28.0 Boosts Kimi-K3 and DeepSeek V4 Performance](https://github.com/vllm-project/vllm/releases/tag/v0.28.0) ⭐️ 8.0/10

vLLM v0.28.0 was released with 584 commits from 270 contributors, introducing major performance optimizations for Kimi-K3 and DeepSeek V4, including new kernels, memory savings, and expanded hardware support. Key additions include Decode Context Parallel (DCP) support, fused FlashKDA kernels, and sparse MLA end-to-end support for DeepSeek V4. This release significantly enhances the inference performance of two prominent open-source models, Kimi-K3 and DeepSeek V4, making vLLM more competitive for large-scale deployment. The optimizations, such as DCP and memory savings, directly address key bottlenecks in long-context and high-throughput serving, benefiting the broader AI/ML community. Notable technical details include a ~60% improvement in DSpark TTFT via an adaptive speculative token budget, ~17 GiB memory savings per GPU from optional shared-expert sharding, and 1.5-3x kernel-level speedups from combined all-gathers. The release also raises the default max_num_batched_tokens from 8192 to 16384 and enables prefix caching by default for Mamba models.

github · khluu · Aug 26, 09:46

**Background**: vLLM is a widely-used open-source library for high-throughput LLM inference, supporting various models and hardware. Context parallelism (CP) is a technique to handle long-context requests by sharding the KV cache across GPUs, which is essential for models like Kimi-K3 that support extremely long sequences. FlashKDA is a set of CUDA kernels developed by Moonshot AI for Kimi's Delta Attention mechanism, which vLLM now integrates to speed up decoding and prefill.

This was achieved by discovering that ACE3 uses the SPMI interface and shares a similar register set with the CD3217 chip. This milestone significantly enhances the usability of Linux on Apple Silicon M3 Macs, enabling faster data transfer and external display connectivity. It represents a major reverse-engineering achievement that brings Linux closer to full hardware support on Apple's latest chips. The ACE3 controller was found to have a register set nearly identical to the CD3217, but it is accessed via the SPMI bus instead of I2C. Both the SPMI interface and ACE3 are now functional in Asahi Linux, enabling USB 3.0 and Thunderbolt on all M3 series devices.
