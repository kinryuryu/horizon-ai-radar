## [Prompt Injection as Role Confusion in LLMs](https://role-confusion.github.io/) ⭐️ 8.0/10

A new paper and blog post argue that prompt injection exploits role confusion in LLMs, showing that human red-teamers achieve near-100% attack success rates against frontier models, even though the same models score near-perfectly on static benchmarks. This reveals a fundamental vulnerability in LLM security that static benchmarks miss, highlighting the need for dynamic, adaptive evaluation methods and fundamentally different architectures to defend against adaptive human attackers. The paper demonstrates that wrapping instructions in <think> tags is ineffective because attackers can mimic the same style in user input, and that non-deterministic security measures are unlikely to be acceptable for critical applications.

hackernews · x312 · Jun 22, 15:48 · [Discussion](https://news.ycombinator.com/item?id=48631888)

**Background**: Prompt injection is a cybersecurity exploit where malicious inputs cause LLMs to behave unintentionally by confusing developer-defined instructions with user input. Role confusion occurs because LLMs process all input in a flattened context window without semantic separation of control and data, making them vulnerable to attacks that static benchmarks fail to capture.

## [Die Analysis of 8087 Coprocessor's Fast Bit Shifter](https://www.righto.com/2020/05/die-analysis-of-8087-math-coprocessors.html) ⭐️ 8.0/10

A detailed die analysis of the Intel 8087 math coprocessor reveals the clever engineering behind its fast bit shifter, which uses a two-stage design (bit shift then byte shift) rather than a log2 barrel shifter. This analysis provides deep insight into the design trade-offs of early floating-point hardware, highlighting how engineers achieved high performance with limited transistor counts. Understanding these historical designs helps appreciate modern processor evolution. The 8087's bit shifter uses a two-stage approach: first shifting by 0-3 bits, then shifting by 0-3 bytes, implemented with a custom decoder and multiplexer network. This design avoids the complexity of a full barrel shifter while still handling the required shift ranges for floating-point normalization.

hackernews · Jimmc414 · Jun 22, 13:40 · [Discussion](https://news.ycombinator.com/item?id=48629982)

**Background**: The Intel 8087, introduced in 1980, was the first floating-point coprocessor for the 8086/8088 microprocessors, accelerating floating-point arithmetic by up to 100x. A bit shifter is a circuit that moves bits left or right by a specified number of positions, essential for floating-point operations like normalization and alignment.
