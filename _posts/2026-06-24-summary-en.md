## [Unlimited OCR: One-Shot Long Document Parsing](https://github.com/baidu/Unlimited-OCR) ⭐️ 8.0/10

Unlimited OCR introduces a method to avoid memory growth in AI document parsing by cleverly managing the KV cache, enabling one-shot processing of long documents without chunking. This breakthrough addresses a key memory limitation in transformer-based OCR models, allowing efficient processing of entire books or long PDFs in a single pass, which could significantly improve document digitization workflows. The method manages the KV cache to prevent linear memory growth with context length, avoiding the need for chunking or sliding windows. The project is open-source on GitHub and builds on models like Deepseek-OCR and PaddleOCR.

hackernews · ingve · Jun 23, 11:35 · [Discussion](https://news.ycombinator.com/item?id=48643426)

**Background**: Transformer-based OCR models use a KV cache to store key and value vectors, which grows linearly with input length, causing memory issues for long documents. Traditional solutions require chunking documents into smaller pieces, which can lose context. Unlimited OCR's approach avoids this by cleverly managing the cache, enabling one-shot processing.

## [Prompt Injection as Role Confusion](https://simonwillison.net/2026/Jun/22/prompt-injection-as-role-confusion/#atom-everything) ⭐️ 8.0/10

Research by Charles Ye, Jasmine Cui, and Dylan Hadfield-Menell shows that LLMs cannot reliably distinguish privileged text from user input via role tags, and that jailbreaks exploiting style over content are highly effective. This confirms fundamental limitations of role-based defenses against prompt injection, with significant implications for LLM security and AI safety. The researchers found that "destyling" text to make it look less like the expected format in a role tag reduced attack success from 61% to 10%, and that models take the style of text more seriously than its actual content.

rss · Simon Willison · Jun 22, 23:59

**Background**: Prompt injection is a cybersecurity exploit where malicious inputs cause LLMs to behave unintentionally. Role tags like <system> and <user> are used to indicate the source of text, but this research shows models infer roles from writing style rather than tags, making them vulnerable to style-based attacks.
